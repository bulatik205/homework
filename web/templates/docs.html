Документация API

Backend для домашки.

Введение

Все эндпоинты возвращают JSON. Базовый URL:

https://hw.bulatik.website

Прямые запросы к https://hw.bulatik.website не требуют секрета.

Формат ответа

Успех:

{
  "success": true,
  "body": { ... }
}

Ошибка:

{
  "success": false,
  "error": "описание ошибки",
  "code": 400
}

GET /api/v1/ping

GET /api/v1/ping
Проверка живости бэкенда.

Ответ

{ "success": true }

GET /api/v1/subjects

GET /api/v1/subjects
Список предметов с кодами и отображаемыми названиями.

Ответ

{
  "success": true,
  "body": [
    { "code": "math", "display": "Алгебра" },
    { "code": "history", "display": "История" }
  ]
}

GET /api/v1/tasks

GET /api/v1/tasks
Список задач. Публичный, без авторизации.

Query-параметры

Параметр Тип Описание
dateoptional string Фильтр по дате сдачи (YYYY-MM-DD). Совпадает с date_to.
subjectoptional string Фильтр по коду предмета, например math.
recencyoptional string last — сортировка по id DESC (последние добавленные). Без параметра — по предмету и id.

Пример

GET /api/v1/tasks?date=2026-10-09
GET /api/v1/tasks?subject=math&recency=last

Ответ

{
  "success": true,
  "body": [
    {
      "id": 1,
      "subject": "math",
      "task": "§5 №12-15",
      "date_from": "2026-10-08",
      "date_to": "2026-10-12",
      "status": null,
      "instead_of": null,
      "created_at": "2026-10-08 22:13:58",
      "updated_at": "2026-10-08 22:13:58"
    }
  ]
}

POST /api/auth/register

POST /api/auth/register
Регистрация нового пользователя по ключу доступа.

Body (JSON)

Поле Тип Описание
usernamerequired string Логин, минимум 3 символа.
passwordrequired string Пароль, минимум 6 символов.
keyrequired string Ключ в формате id:original.

Ответ

{
  "success": true,
  "body": {
    "id": 2,
    "username": "bulat",
    "role": "user",
    "created_at": ""
  }
}

Устанавливает cookie session_str.

POST /api/auth/login

POST /api/auth/login
Вход по логину и паролю.

Body (JSON)

Поле Тип Описание
usernamerequired string Логин.
passwordrequired string Пароль.

Ответ

{
  "success": true,
  "body": {
    "id": 1,
    "username": "bulat",
    "role": "admin",
    "created_at": "2026-10-08 20:15:00"
  }
}

POST /api/auth/logout

POST /api/auth/logout
Выход. Очищает session_str в БД и удаляет cookie.
{ "success": true }

GET /api/auth/me

GET /api/auth/me
Информация о текущем пользователе. Требует cookie session_str.
{
  "success": true,
  "body": {
    "id": 1,
    "username": "bulat",
    "role": "admin",
    "created_at": "2026-10-08 20:15:00"
  }
}

401 если сессия отсутствует или истекла.

GET /api/admin/tasks

GET /api/admin/tasks
Только для админов. Список задач.

Query-параметры

Параметр Тип Описание
dateoptional string Фильтр по дате сдачи (YYYY-MM-DD).

Лимит: 500 записей. Сортировка: по предмету и id.

POST /api/admin/tasks

POST /api/admin/tasks
Только для админов. Создание задачи.

Body (JSON)

Поле Тип Описание
subjectrequired string Код предмета.
taskrequired string Текст задания.
date_tooptional string Дата сдачи (YYYY-MM-DD).
date_fromoptional string Дата выдачи.
statusoptional string Статус (todo, done, ...).
instead_ofoptional string Код предмета, вместо которого задана задача.

Пример

{
  "subject": "social",
  "task": "параграф 5",
  "date_to": "2026-10-09",
  "instead_of": "history"
}

Ответ

{
  "success": true,
  "body": { "id": 12, "subject": "social", ... }
}

PATCH /api/admin/tasks/{id}

PATCH /api/admin/tasks/{id}
Только для админов. Обновление задачи. Все поля обязательны.

Body (JSON)

Те же поля, что и при создании.

Пример

PATCH /api/admin/tasks/12
{
  "subject": "social",
  "task": "параграф 5-6",
  "date_to": "2026-10-09",
  "instead_of": "history"
}

DELETE /api/admin/tasks/{id}

DELETE /api/admin/tasks/{id}
Только для админов. Удаление задачи.
{ "success": true }

GET /api/admin/subjects

GET /api/admin/subjects
Только для админов. То же, что /api/v1/subjects.

GET /api/admin/schedule/day

GET /api/admin/schedule/day
Только для админов. Уроки по расписанию на конкретный день.

Query-параметры

Параметр Тип Описание
daterequired string Дата (YYYY-MM-DD).

Ответ

{
  "success": true,
  "body": {
    "date": "2026-10-09",
    "day": 4,
    "day_name": "Пт",
    "lessons": [
      { "code": "math", "display": "Алгебра" },
      { "code": "history", "display": "История" }
    ]
  }
}

GET /api/admin/schedule/next

GET /api/admin/schedule/next
Только для админов. Ближайшая дата, когда стоит указанный предмет. Сегодняшний день не учитывается — только будущее.

Query-параметры

Параметр Тип Описание
subjectrequired string Код предмета.

Ответ

{
  "success": true,
  "body": {
    "date": "2026-10-15",
    "day": 3,
    "day_name": "Чт"
  }
}

404 если урок не найден в ближайшие 14 дней.
